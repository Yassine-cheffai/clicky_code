1. Raylib-Swift (Le meilleur choix multiplateforme)
Raylib est une bibliothèque C très populaire pour l'apprentissage et la création de jeux 2D/3D légers. Grâce à des bindings Swift maintained par la communauté, vous pouvez utiliser toute l'API de Raylib directement en Swift.

Plateformes supportées : macOS, Linux, Windows, iOS, Android, Web (Wasm).

Philosophie : Aucune interface graphique complexe ou éditeur de scènes. Vous gérez tout par le code (fenêtre, rendu, entrées, audio).

Exemple d'installation : S'intègre directement via Swift Package Manager (SPM).
